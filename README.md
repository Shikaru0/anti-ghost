# anti-ghost
Unofficial continuation of https://github.com/TheMasterKitty/AntiGhost/tree/master (Modrinth page: https://modrinth.com/mod/anti-ghost)

Automatically re-updates your inventory in an attempt to prevent / minimize ghosting in Crystal PvP and other gamemodes. This can't prevent network based ghosting due to lost or delayed packets but can help your inventory update faster.

## Is this allowed on MCTiers?
The original mod states:
'**Allowed on MCTiers!**'
This mod just does small mapping conversions to make it work on different versions, if the original mod is allowed, this continuation would most likely be allowed aswell, but I haven't checked yet.
